# Локальная OCR-система для распознавания ТТН (─‿‿─)

Этот проект посвящен разработке системы для локального распознавания и извлечения структурированных данных из товарно-транспортных накладных (ТТН). Система спроектирована для работы без доступа к интернету, обеспечивая полную конфиденциальность документов.

## Основная документация

Вся техническая информация и план реализации разделены на два модуля:

### 1. [Анализ и Архитектура](Analysis_and_structure.md)
В этом файле содержатся:
* **Анализ стека:** Сравнение Tesseract, EasyOCR и выбор в пользу **PaddleOCR**.
* **Структура данных:** Описание целевого JSON-формата (метаданные, участники, сведения о ТС и таблица товаров).
* **Проектирование:** Логическая схема работы системы — от препроцессинга изображения с помощью OpenCV до финального парсинга данных.

### 2. [Дорожная карта (Roadmap)](Roadmap.md)
В этом файле представлен пошаговый план разработки:
* **Lab 1-2:** Формализация требований и проектирование системы.
* **Lab 3-4:** Разработка модулей загрузки, предобработки и первичного распознавания.
* **Lab 5-6:** Финальная сборка стенда на Streamlit/FastAPI, обработка ошибок и подготовка демонстрации.

---
*Проект разрабатывается как демонстрационный стенд для автоматизации обработки первичной документации.* (≧◡≦)
